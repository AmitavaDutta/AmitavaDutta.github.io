# Amitava Dutta — Personal Website

This repository contains the source code for my personal website:

**[amitavadutta.github.io](https://amitavadutta.github.io/)**

The website is built using [Jekyll](https://jekyllrb.com/) and the
[**Chirpy Jekyll Theme**](https://github.com/cotes2020/jekyll-theme-chirpy),
created and maintained by **Cotes Chung**.

## About

I am a PhD student in Geodynamics in the Department of Earth and Climate Sciences (ECS) at IISER Pune.

This website brings together information about my:

- Research
- Publications
- Teaching
- Education
- Curriculum Vitae
- Resources
- Gallery

It also serves as a place to share some of the things I work on, learn, and occasionally spend far too much time debugging.
